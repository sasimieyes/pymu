PDF 변환기

사용법

빠른 시작

  1. 드롭존에 파일을 끌어다 놓거나 클릭해서 선택
  2. (선택) 회전 / 순서 / 병합 그룹 조정
  3. (선택) OCR / AI 오탈자보정 토글 확인
  4. PDF로 변환 클릭 → 진행률 표시 → 자동 다운로드

옵션 설명

회전

각 파일 옆 ↻ 회전 버튼을 누르면 90° 단위로 시계방향 회전합니다. 썸네일이 즉시 회전되어 결과 방향을 미리 확인할 수 있습니다.

병합 / 단독 분리

각 파일 옆 병합 체크박스를 사용합니다. 체크된 파일들은 하나의 PDF 로 병합되고, 체크 해제된 파일은 각각 단독 PDF 로 출력되어 zip 으로 묶여 다운로드됩니다.

OCR

이미지나 스캔 PDF 에 보이지 않는 텍스트 레이어를 추가해 검색·복사·붙여넣기를 가능하게 합니다. 한국어, 영어, 숫자 인식을 지원합니다.

AI 오탈자보정

OCR 결과의 한글 띄어쓰기 누락이나 명백한 오탈자(예: "수십역" → "수십억")를 로컬 LLM 으로 교정합니다. 정확도는 향상되지만 변환 시간이 크게 늘어납니다.

주의 / 한계

  • 업로드 파일 크기 한도: 요청당 200 MB
  • 결과물의 모든 페이지는 A4 portrait (210 × 297 mm) 로 통일됨
  • 한 번에 한 작업씩 처리 (큐), 대기자에게는 순번 표시
  • 변환 도중 탭을 닫으면 작업이 자동 취소되고 다음 대기열로 넘어감
